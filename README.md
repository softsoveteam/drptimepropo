# Softsove × Dr.Prime — Digital Growth Plan

Interactive Next.js proposal for **Dr.Prime / PrimeHeal**, styled in Softsove’s dark + purple brand language.

**Access password:** `letsroll`

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s inside

- Softsove logo & company details from [softsove.com](https://softsove.com)
- Full Digital Growth Plan: Google Ads · Meta Ads · SEO
- Sections: overview, understanding, market, channels, process, tracking, budget, next steps
- Animated hero, marquees, sticky nav with scroll spy

## Stack

Next.js (App Router) · Tailwind CSS v4 · Framer Motion · Lucide
